# Практическая работа № 31

Vue Router: навигация, параметры, query.

Репозиторий: https://github.com/Arbuzkin/practica31

Демо на GitHub Pages: https://arbuzkin.github.io/practica31/

## Что сделано

- подключён `vue-router@4` в `src/main.js`;
- настроены маршруты в `src/router/index.js`;
- главная страница с навигацией (`/`);
- список товаров с фильтрацией через query-параметр (`/products?filter=electronics`);
- страница товара с параметром пути (`/products/:id`) и передачей `params` через `props`;
- страница входа (`/login`), пароль — `demo`;
- защищённый маршрут `/dashboard` и глобальный guard;
- выход из защищённой страницы очищает `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу `http://localhost:5173/`.

## Проверка

1. Открыть «Список товаров» и переключить фильтры — фильтр сохраняется в URL.
2. Перейти на товар — ID берётся из параметра пути.
3. Открыть «Панель управления» без входа — произойдёт редирект на `/login`.
4. Ввести пароль `demo` — откроется защищённая страница.
5. Нажать «Выйти» — токен удалится, снова откроется страница входа.
